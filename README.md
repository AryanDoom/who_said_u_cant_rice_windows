this is my windows setup.

basically everything i've installed and configured to make windows look less like normal windows and make my workflow actually feel good.

a lot of this started with just wanting a transparent terminal and then i kept installing more shit.

## the setup

### terminal

**wezterm**

my main terminal.

transparent, customizable and where i do most of my development stuff.

---

### shell / linux stuff

**wsl**

because windows terminal commands can only take me so far.

most of my development environment runs through wsl.

---

### editor

**neovim**

my main editor.

still configuring it and making it more comfortable for daily coding. trying to get the useful parts of vscode without actually opening vscode.

---

### file manager

**yazi**

terminal file manager.

fast and actually nice to use compared to typing `cd` fifty times.

---

### app launcher

**flow launcher**

used for launching apps, searching for stuff and generally not having to go through the start menu.

---

### widgets

**yasb**

for the status bar / widgets and making the desktop look less empty.

---

### browser

**zen browser**

because apparently even my browser needed to be part of the rice.

---

### window manager

**glazewm**

for tiling windows instead of manually dragging everything around like windows expects me to.

still messing with the layout and configuration.

---

### powertoys

mostly for random quality of life stuff that windows should probably have by default.

---

### everything

good windows search engine (actually works and fast enough)

---


### terminal tools

**bat**

basically `cat` but better.

syntax highlighting and nicer output because apparently even reading a file needs to look good.

**htop**

system monitor in the terminal.

**cava**

terminal audio visualizer because there is absolutely no reason my terminal should not have bars moving when music is playing.

---

## why this repo exists!


because i've changed enough random configs at this point that if i lost them all i'd probably just stare at my screen for a few hours.

this repo keeps all of that in one place.

also makes moving the setup to another machine significantly less painful.

---

## the goal

i want a setup that is:

* fast
* keyboard focused
* customizable
* actually nice to look at
* good for development
* not dependent on vscode for everything

basically:

> windows when i actually have control over what it looks like.
